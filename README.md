# ItsMeGames

Landing de ItsMeGames y del juego Layer 8.

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 y Motion.

## Desarrollo

```bash
npm install
npm run dev
```

## Variables de entorno

Copiá `.env.example` a `.env.local` y configurá:

- `NEXT_PUBLIC_CLARITY_ID`: identificador público opcional de Microsoft Clarity.
- `LAYER8_SIGNUP_URL`: URL privada del Google Apps Script que recibe las inscripciones de Layer 8.
